一、我修改过的源文件
--------------------
1. libcore/gomobile/cmd/gomobile/env.go
   - 改动类型：修改（该文件所在的 libcore/gomobile/ 目录由 libcore/init.sh 从
     https://github.com/MatsuriDayo/gomobile 克隆生成，属未跟踪文件）
   - 改动内容：函数 archNDK() 中新增：
         if runtime.GOOS == "linux" { arch = "x86_64"; break }
     即 linux/arm64 主机也使用 NDK 的 linux-x86_64 预编译工具链。
   - 原因：Android NDK 只提供 linux-x86_64 的 host 工具链；原代码在 arm64 Linux
     上直接 panic: unsupported GOARCH: arm64。
   - 运行方式：本机已启用 qemu-x86_64 binfmt，x86_64 的 clang 等工具可直接执行。
   - 修改时间：2026-11-14 13:47
   - 生效方式：在 libcore/gomobile/cmd/gomobile 下重新 go install，并把生成的
     gomobile 覆盖为 ~/go/bin/gomobile-matsuri。

四、我自己执行过的关键命令（复现用）
----------------------------------
  source ~/android-env.sh
  cd /home/Gold/workspace/nekobox
  bash buildScript/lib/assets.sh
  cd libcore && GOBIND=gobind-matsuri CGO_ENABLED=1 \
    gomobile-matsuri bind -v -androidapi 21 -cache "$(realpath .build)" -trimpath \
    -ldflags='-s -w' -target=android/arm64 \
    -tags='with_conntrack,with_gvisor,with_quic,with_wireguard,with_utls,with_clash_api' .
  cp -f libcore.aar ../app/libs/
  cd .. && ./gradlew app:assembleDebug

    app/build/outputs/apk/oss/debug/NekoBox-1.4.2-arm64-v8a-debug.apk

  注：设备原有 moe.nb4a.debug 是用另一把调试密钥签名的，不能覆盖安装。
